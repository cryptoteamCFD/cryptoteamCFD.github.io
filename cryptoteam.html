How an NFT receipt gets minted

A typical proof-of-purchase flow, from checkout to wallet.

  1. The customer adds a wallet address at checkout.
  2. Shopify sends an order-paid webhook to a small server.
  3. The server verifies the webhook signature and queues a mint.
  4. The certificate lands in the customer's wallet.
orders-paid.js (illustrative sketch)
// sketch only, not production code
app.post('/webhooks/orders-paid', verifyShopifyHmac, async (req, res) => {
const order = req.body;
const wallet = order.note_attributes
.find(a => a.name === 'wallet')?.value;
if (!isAddress(wallet)) return res.sendStatus(200);
 
await queue.add('mint-receipt', {
orderId: order.id,
to: wallet,
sku: order.line_items[0].sku,
});
res.sendStatus(200);
});

Questions

Which crypto payment providers do you integrate?

We pick per project, based on your country, volume and fee tolerance. Providers differ in supported regions and Shopify compatibility, so we confirm this when we scope the work.

Do I have to take payment in crypto?

No. Card and bank transfer stay available. Crypto is added as an option in stablecoins, ETH and BTC.

Which blockchain do you build on?

Token gating and NFT features are typically built on Ethereum or an EVM-compatible network. We confirm the chain with you when we scope the work.

Do you give tax or legal advice?

No. We connect your order data to accounting tools. How crypto sales are taxed and regulated depends on your country, so ask a qualified accountant or lawyer.

Will you change my live store?

Not before you approve a milestone. We build on a separate theme or a duplicate first.

Send your store URL and what you want to add. We reply with a fixed quote and a milestone list. You can also write to hello@cryptoteam.cfd.
